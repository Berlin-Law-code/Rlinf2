# 评测归一化区间计数

在已有 `env.eval.episode_log` 中增加 `norm_stats_paths: {old: /path/old.json, new: /path/new.json}`，可对同一批状态/动作同时按多个统计区间计数。默认不启用，仅支持已有的评测回合日志。

每个完成回合的 JSON 行增加 `norm_range`：`policy_state` 统计有效环境每个动作块开始时的状态；`transition_state` 统计真实执行步之前的状态；`policy_action` 为真实执行步对应的策略输出（夹爪阈值化前）；`executed_action` 为后端报告的命令。末端命令不代表测得的实际关节位置。终止后填充步和无真实转换的调用不计入执行步统计。

每种统计保留 8 维的低于/高于区间次数、超出归一化边界至少 0.01 的次数、归一化最小/最大值；关节汇总和 `any_joint_outside_vectors` 只包含前七维，夹爪单列。其分位数直方图可能产生 0.9998 上界，因此实际合法状态 1 也会轻微超界。

`low_token_saturated_per_dim` 和 `high_token_saturated_per_dim` 只对状态有效，对应生产 `np.digitize` 的 -1 和 255 编码；高边界格从 1-2/256 开始，不能与严格超出 [-1,1] 完全混同。q01/q99 不是机器人关节硬限位。

观察器不截断、更改状态或动作，不保存图片、视频或逐步轨迹。它不改变训练或评测的模型统计。回合未完成时计数只保存在内存中。按执行步汇总会给长轨迹更大权重，分析时应同时列出逐回合均值和成功/失败分组。
